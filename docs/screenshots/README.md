# Screenshots

Drag your own screenshots into this folder using these exact filenames -
the main `README.md` already references them, so they'll show up there
automatically once added (no markdown editing needed):

| Filename | Suggested shot |
|---|---|
| `dashboard.png` | The dashboard page - today's sales, stock alerts, udhaar exposure |
| `khata.png` | A party's khata (ledger) detail view with the aging buckets |
| `munshi.png` | The Munshi AI chat, ideally mid-conversation with a tool-citation footer visible |
| `mobile.png` | The Expo app - dashboard or Munshi AI screen, phone-shaped |

PNG or JPG both work. No strict size requirement - GitHub scales them to
fit, but ~1200px wide is a good target for the web screens and a normal
phone screenshot resolution for the mobile one.
